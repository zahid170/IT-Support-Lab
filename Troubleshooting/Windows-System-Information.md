# Windows System Information Collection

## Scenario

A user reports that their computer is running slowly.

## Objective

Gather system information before troubleshooting.

## Tools Used

- msinfo32
- winver
- systeminfo

## Procedure

### Step 1

Press:

Windows + R

Type:

msinfo32

### Step 2

Review:

- Processor
- RAM
- BIOS Version
- Operating System

### Step 3

Open Command Prompt

Run:

```cmd
systeminfo
```

### Step 4

Record findings.

## Result

Successfully collected system information for troubleshooting.

- Windows Administration
- Troubleshooting Methodology
- Information Gathering
